## Stack

- React 18 / React Router v6
- EmailJS (contact form)
- GitHub REST API (project feed)
- CSS custom properties — Space Mono / Orbitron / Poppins

## Run Locally

```bash
npm install
npm start
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

Builds the app and publishes to the `gh-pages` branch, updating the live site above.
